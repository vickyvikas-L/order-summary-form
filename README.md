# 🛒 Order Summary Form

A simple and responsive **Order Summary Form** project created using **HTML5 and CSS3**. The project displays an order summary with product details, pricing information, and a checkout section.

## ✨ Features

* 🛍️ Product/order details
* 💰 Displays product price and total amount
* 📦 Order summary section
* 💳 Checkout/payment section
* 🔘 Interactive buttons
* 📱 Responsive design
* 🎨 Clean and simple user interface

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📌 Project Objective

The objective of this project is to practice creating a **structured order summary and checkout UI** using HTML and CSS.

## 🎯 Concepts Practiced

* HTML Forms
* Input fields
* Buttons
* CSS Flexbox
* CSS Grid
* Box Model
* Margins and Padding
* Borders and Border Radius
* Responsive Web Design
* Basic UI Design
